# SQL Practice: Selecting Data with SQL

## Project Overview
This project is part of my Data Science learning journey. It focuses on retrieving, selecting, and transforming data from a SQLite database using SQL queries in Python.

## Tools and Technologies
- Python
- SQLite
- Pandas
- Jupyter Notebook
- Visual Studio Code
- Git and GitHub

## Dataset
The project uses the `data.sqlite` database, which contains a `products` table used to practice SQL queries.

## Learning Objectives
The exercises cover:
1. Selecting specific columns using `SELECT`.
2. Changing the order of selected columns.
3. Applying conditional logic with `CASE WHEN`.
4. Measuring string length using `LENGTH()`.
5. Converting text to uppercase and lowercase.
6. Extracting text using `SUBSTR()`.
7. Combining text using concatenation.
8. Calculating and rounding numerical values.

## Project Files
- `dsc_c1w1m1_practice2.ipynb` — SQL practice notebook.
- `data.sqlite` — SQLite database.
- `README.md` — Project documentation.

## How to Run
1. Clone the repository.
2. Open the project in VS Code or Jupyter Notebook.
3. Select a Python environment with pandas installed.
4. Run the notebook cells to connect to the SQLite database and execute the SQL queries.

## Key Takeaways
This practice helped me strengthen my understanding of SQL queries, database connections, data selection, and basic data transformation using Python and pandas.
